# QuantumGold (QG) Parity Workflow

## Overview
QuantumGold is an industry standard used internally by laboratories to define peak structures and background geometries. FluxForge can perfectly reproduce equivalent evaluations of HPGe files.

## Workflow Alignment
- Reads baseline text outputs generated by QG (`.txt`).
- Analyzes custom ROIs and area calculations alongside the initial data.
- Achieves tight delta tolerances (under 8%) without breaking broader ASTM standards.
- FluxForge implements parity tests to consistently ensure metrics don't drift away from QG baseline files.
