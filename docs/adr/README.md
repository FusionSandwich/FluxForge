# FluxForge ADRs

Architecture Decision Records document durable technical decisions that shape the
FluxForge roadmap. They are intentionally short and focus on context, the decision,
alternatives considered, and consequences.

## Status Values

- `Proposed`
- `Accepted`
- `Superseded by ADR-NNN`

## Template

```markdown
# ADR-NNN: Short Title

**Status:** Accepted

## Context
[Why this decision is needed.]

## Decision
[The concrete decision.]

## Rationale
[Why this option was chosen.]

## Alternatives Rejected
- [Alternative] — [Reason rejected]

## Consequences
- [What follows from the decision.]

## Compliance with Project Rules
- Issue-First Execution: [impact]
- Additive Capability Policy: [impact]
- User-Choice Policy: [impact]
- Standards-Locked Workflows: [impact]
```
