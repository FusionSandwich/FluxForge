# Spectroscopy Demo Data

This directory contains small bundled spectroscopy assets used by the
validation-style example scripts.

## Files

- `Eu152_point.mcd`
- `Eu152_point.txt`
- `152Eu_point_source.yaml`
- `152Eu_peaks.yaml`
- `background.mcd`
- `background.txt`
- `background_peaks.yaml`
- `example_sample.mcd`
- `example_sample.txt`

## Where These Files Are Used

These assets support the validation-oriented demos documented in:

- [examples/validation/README.md](/groupspace/cnerg/users/smandych/projects/ALARA/FluxForge/examples/validation/README.md:1)
- [examples/README.md](/groupspace/cnerg/users/smandych/projects/ALARA/FluxForge/examples/README.md:1)

They are intended as small committed parser, calibration, and plotting inputs
rather than as a single monolithic workflow.
